# UI review — 2026-07-28

Four parallel reviews of `App/` (Sky mode chrome, Galaxy Map, browse screens, design/HIG),
run with the swiftui-pro review skill. This doc is the source of truth for the findings and
the fix plan; check items off as they land.

## Verdict

The design taste is present and real: the luminous glass language, the serif large-title
voice, `CircleIconButton` (44pt targets, required labels, haptics, selection traits),
`ObserverLocation`'s Swift 6 patterns, and the Metal renderer's buffer management
(`sceneVersion` guard — instance buffers only rebuild when the scene actually changes)
are all done right. The gap to "genuinely beautiful" is three specific, fixable themes:
**motion has no system**, **~30% of surfaces bypass the design system**, and
**main-thread hitches in exactly the places the app should feel effortless**.

Conventions verified clean by all reviewers: no emoji-presentation glyphs (U+FE0E applied
correctly), no third-party frameworks beyond SwiftAA, `foregroundStyle` throughout, no
`Binding(get:set:)` abuse in Sky mode, motion/AR lifecycle correctly paired, sensor
delegate → MainActor hops correct.

## Theme 1 — Motion has no system (largest perceived-quality win)

- Five different animation curves in use, no shared token: spring 0.3
  (`GalaxyMapView.swift:193,323`), spring 0.35 (`ContentView.swift:811`), default
  `withAnimation {}` (`ContentView.swift:397,411`), easeOut 0.15
  (`LuminousButtonStyle.swift:26`), easeIn 0.6 / easeOut 1.2 / easeInOut 0.4 (dive).
- Selection cards **pop in/out with no transition** in both HUDs: `selection` set raw in
  tap handlers (`ContentView.swift:577-580` → conditional at `:357`; GalaxyMapView tap
  handler → conditional at `:214`). The options panel *does* transition
  (`.move + .opacity`, `GalaxyMapView.swift:236`) — the app visibly has two standards.
- `calibrationBar` (`ContentView.swift:359`) and `StarColorLegend` (`:363`) also appear
  unanimated.
- No `.contentTransition(.numericText())` anywhere despite live readouts (pointing line,
  DistanceReadout, SpeedReadout).
- The chrome-rotation spring (`ContentView.swift:811`) is the only spring personality in
  the app — and it ignores Reduce Motion (Reduce Motion honored in only 2 files:
  `SystemView.swift:9`, `GalaxyMapView.swift:68`).

**Fix:** define `Theme.spring` (e.g. `.spring(duration: 0.35, bounce: 0.15)`) and
`Theme.transition` (`.move + .opacity`, matching the options panel); wrap every selection
mutation; give selectionCard / calibrationBar / timeScrubber / StarColorLegend the
transition; `numericText` on live readouts.

## Theme 2 — Surfaces that bypass the design system

- **CatalogView is off-world:** plain system `List`, no space gradient, no
  `.scrollContentBackground(.hidden)` (`CatalogView.swift:27-102`) while sibling
  `ConstellationsView` does the full treatment (`ConstellationsView.swift:73-107`).
  Also hand-rolls a bottom search field (`CatalogView.swift:109-133`) while
  ConstellationsView uses `.searchable` — siblings shouldn't differ.
- **Glass + flat plates mixed in one stack:** `selectionCard` is luminousSurface but
  `bottomPanel` below it is `.black.opacity(0.35)` (`ContentView.swift:538`);
  `StarColorLegend` `.black.opacity(0.35)` r14 (`StarComparisonViews.swift:172`); HR/size
  plots `.black.opacity(0.25)` r12 (`StarComparisonViews.swift:62-63,119-120`).
- **Token leaks:** 11 ad-hoc corner radii vs Theme's 2 (six distinct radii on the sky
  screen alone); **27 distinct `white.opacity()` values** standing in for a text
  hierarchy (secondary text is variously 0.5/0.55/0.6/0.65/0.7/0.75/0.82/0.85); 17
  padding literals; **four different "space blacks"** (`Theme.spaceGradient`,
  `ContentView.swift:279`, `MoreMenu.swift:165`, `GalaxyMapView.swift:98`).
- **Triplicated component:** `DetailRow` (`CatalogView.swift:511-527`) ≡
  `PlanetDetailView.row` (`:106-116`) ≈ `DetailFactRow` (`ConstellationsView.swift:287-302`,
  missing the GlossaryButton the others have). Extract one shared DesignSystem row.
- **Bug:** `.listRowBackground` applied to the whole Form is a silent no-op
  (`SkyFilters.swift:79`) — filter sheet rows never get their intended tint.
- Temperature color thresholds duplicated verbatim (`StarComparisonViews.swift:180-191`
  vs `StarFacts.swift:350-359`).

**Fix:** `Theme.quietSurface` (or reuse luminousSurface) for the flat plates; collapse
radii onto card/panelRadius; add 3 semantic text-emphasis tokens (primary/secondary
`.white.opacity(0.65)`/tertiary `0.5`, floor informational text at ≥0.55) and sweep; one
spaceGradient everywhere; CatalogView gets gradient + hidden scroll background + the
luminous row treatment; unify search; shared `DetailRow`.

## Theme 3 — Main-thread hitches

Sky mode (`ContentView.swift` + `Sky/`):
- **F1 (high):** `solarState` runs full Sun (Meeus 25) + Moon (60+60-term ELP +
  parallax + refraction) per display tick — up to 120 Hz — at `:88-91`/`:596-625`, plus a
  duplicate at `:366-369`. Cache az/alt on the 1.5 s `refreshSky()` like `planetGlyphs`.
- **F2 (high):** `refreshSky()` (`:627-706`) does ~9k+ transforms + sort on the main
  actor every 1.5 s. Move to a `nonisolated` builder off-main.
- **F3 (high):** AR passthrough creates a full-res `CGImage` via CIContext every tick
  even with no new frame (`:79-85`, `ARCameraController.swift:69-73`). Cache keyed on
  `frame.timestamp`.
- **F5 (med):** per-frame `uppercased()` + `Text` builds in the Canvas label pass
  (`:222-253`). Precompute at refresh time.
- Misc: deprecated `MagnificationGesture` (`:559`); `String(format:)` at
  `:528-530,547,937,942`; hardcoded `"EEE HH:mm"` formatter (`:426-437`) forces 24-hour;
  dead `isPointingReady` (`SkyMotionProvider.swift:23`); dead `projectToScreen`
  (`SkyProjection.swift:44-60`, duplicates `SkyCamera.motion` math); eager
  `ARSession`/`CIContext` at launch (`ARCameraController.swift:23-24`); FilterSheet
  `filter{}.count` full scan per slider tick (`SkyFilters.swift:96` → `count(where:)`).
- Named refactor seams in the god-object: `skyCanvas` (`:157-256`), chrome cluster
  (`:353-554`), calibration state machine (`:742-831` → testable `CalibrationModel`).

Galaxy Map (`GalaxyMapView.swift` + `Galaxy/`):
- **NM-1 (high):** `NebulaLibrary` doc says "caches" but has **no cache**
  (`NebulaModel.swift:14,50-80`) — every scene rebuild re-reads + re-parses all 27 `.nbl`
  files (25 MB, ~1.25M particles) on the main actor.
- **GM-1 (high):** `buildScene` (`:504-948`) rebuilds *everything* synchronously on the
  main actor from cheap toggles (`hostsOnly`, `showMilkyWay` at `:282,285`). Split into
  cached sprite groups; build async (`GalaxySceneBuilder`).
- **GM-2 (high):** free-fly/fly-to camera mutates `@State` every 16 ms → full 1692-line
  body re-diff 60×/s (`:41-57,956-978,1166-1179`). Route through an imperative channel
  (the `DiveChannel` pattern is the in-repo template) or an `@Observable` leaf.
- **MR-1 (med):** MTKView keeps rendering behind `fullScreenCover`s
  (`GalaxyMetalRenderer.swift:741-744`; covers at `GalaxyMapView.swift:132-143`). Plumb
  `isPaused`.
- **GM-3 (med):** annotation Canvas resolves + measures every landmark label every frame
  (`:150-180`). Precompute sizes/positions.
- **GM-4 (med):** 16 ms `Task.sleep` animation loops drift vs the display link; advance
  the camera in `render(in:)` instead.
- **MR-2 (med):** sprite arrays retained in `@State` after GPU upload — order-100 MB
  duplicated. Drop CPU copy post-upload.
- **SV-1 (med):** `SystemView` recomputes `placed`/`radii` (Kepler math) per planet per
  frame in a `TimelineView(.animation)` (`SystemView.swift:23-28,64-76`). Cache in init.
- Misc: drag jump when throttle interleaves drag (`:1184-1199` — update `dragPrevious`
  in the guard path); deprecated `MagnificationGesture` (`:1202`); unmanaged 8 s epilogue
  task (`:1083-1086`); missing `reserveCapacity` on landmarkLight/overlay (`:513-516`);
  `Task.detached` where plain Task suffices (`Exoplanets.swift:120-139`); debug frame-dump
  GPU race (`GalaxyMetalRenderer.swift:352-369,699-704`, `-dumpDive` only);
  `String(format:)` sweep (`:349,360,1527-1532,1551`, SystemView, BlackHoleDive).
- Verified NOT a problem: representable/coordinator plumbing (buffers rebuild only on
  `sceneVersion` change); exoplanet CSV column names match the code.

Browse screens:
- **(high)** `ConstellationsView.rebuild()` wired to both `.task(id:)` AND `.onAppear`,
  no `figures.isEmpty` guard (`:113-114,30-34`) — full `StarResolver` build over 109k
  stars runs **twice** per appearance and again per pop-back, on the main actor.
- **(high)** `SkyFigureDetailView.stars`/`brightest` computed properties = 3 full-catalog
  trig scans per body evaluation (`:187-209`). Move to `@State` populated in `.task`.
- **(high)** CatalogView `.task` sorts + buckets 109k stars on the main actor
  (`:85-101`); search scans the full catalog per keystroke with ~4 `.lowercased()` per
  star (`:179-182` + `StarFacts.matches:275-284`). Off-actor + precomputed lowercase keys.
- **(med-high)** `Constellation3DModel.build` runs synchronously on the MainActor during
  the cover's presentation animation (`Constellation3DView.swift:226-251,379-453`).
- **(med)** `TonightView` `.task(id: observer.latitude)` — longitude-only changes never
  recompute → **wrong rise/set silently** (`:47`); also the `computing` flag drops the
  newest location (`:258-270` — delete flag, rely on `.task(id:)` cancellation).
- **(med)** Value-based navigation used nowhere; `AppScreen` already `Hashable` →
  `navigationDestination(for:)` starting at MoreMenu (`:65-85`), then row links.
- Misc: 3 hand-rolled 16 ms sleep loops in Constellation3DView (`:256-274,305-320,329-351`
  → `TimelineView(.animation(paused:))`); deprecated `MagnificationGesture` (`:291-299`);
  deprecated `overlay(_:alignment:)` form (ConstellationsView `:158,254-255,300`,
  CatalogView `:130,525`, PlanetDetailView `:115`, StarComparisonViews `:63,120`);
  `ForEach(Array(x.enumerated()))` (TonightView `:123,132,150,180`); dead
  `PlaceholderScreen` + `AppScreen.gradient` (`MoreMenu.swift:194-285`); geometry types
  (`SkyRegion`/`StereographicProjection`/`StarColor`) live inside ConstellationsView.swift
  but are used by Constellation3DView — split out; `StarFacts.constellations` dict
  duplicates `ConstellationCatalog` names (`StarFacts.swift:232-256`); `SkyFigure.id`
  built from user-facing `FigureCatalog.rawValue` (`SkyFigures.swift:149`); stray
  `import SwiftUI` in data files (SkyFigures, ConstellationCatalog);
  `Task.sleep(nanoseconds:)` in debug harness (`AstrolabeApp.swift:81`).

Accessibility top-5 (full spec deferred — these are the highest-impact):
1. No `@ScaledMetric` anywhere; 18 fixed-size fonts + fixed frames (132pt picker
   `ContentView.swift:392`, 64pt thumbnails).
2. Contrast: tiny type at `white.opacity(0.38-0.5)` on black (DistanceReadout
   `GalaxyMapView.swift:1513`, hint `:219`, axis labels, selection detail line
   `ContentView.swift:461` — `.caption2` at 0.5 is the densest line on the card).
3. Canvas data-viz invisible to VoiceOver (HRDiagram/StarSize/ConstellationFigure/sky) —
   one-sentence labels are cheap for the two widgets.
4. No non-tap selection path on either main surface.
5. Reduce Motion honored in only 2 files.

HIG misc: options-panel rows ~38pt (<44) (`GalaxyMapView.swift:315`); segmented picker
frozen at 132pt truncates at large text (`ContentView.swift:392`); "aligned ✓" text char
instead of SF symbol (`ContentView.swift:505`); PlanetDetailView close button lacks
explicit 44pt frame (`:30-34`).

## Session plan

1. **Motion pass** *(✅ done 2026-07-28, builds clean)* — `Theme.spring`
   (`.spring(duration: 0.35, bounce: 0.15)`) + `Theme.slide(from:)` tokens; selection
   set/clear animated in both HUDs (tap handlers, close buttons, initial focus);
   transitions on selectionCard (top), timeScrubber (top), calibrationBar (top),
   StarColorLegend (bottom), Galaxy selection card (bottom) + hint cross-fade; mode
   picker binding animated; ad-hoc springs unified onto the token;
   `.contentTransition(.numericText())` on the time-scrubber label and throttle %.
   **Deliberate deviations:** numericText NOT applied to DistanceReadout or the
   pointing line — those update continuously (per frame / per 0.25 s), where rolling
   digits would churn; `monospacedDigit` is the right treatment there. Dive-epilogue
   fades and `LuminousButtonStyle`'s 0.15 s press kept as intentional separate
   speeds. Motion tokens ported to Ecliptica's `Theme.swift` (builds clean too).
   Reduce Motion support still pending (accessibility item).
2. **NebulaLibrary cache + scene-rebuild split** *(✅ done 2026-07-28, builds clean,
   zero warnings)* — `NebulaLibrary` now truly caches (`Mutex`-guarded, failures
   cached too; `NebulaParticleSet: Sendable`). `buildScene` split: landmark/nebula
   sprites (the ~1.25M-particle half, toggle-independent) generate once into
   `LandmarkSpriteGroups` cached in `@State`; `assembleScene` is a `nonisolated
   static` pure function; the whole rebuild runs in `Task.detached` with
   cancel-previous, so options toggles no longer freeze the UI at all. Bonus: MR-1
   fixed — `GalaxyMetalView` gains `paused:`, wired to `shownSystem != nil ||
   showCatalog`, so the map stops rendering behind full-screen covers.
   On-device verification pending (as with the motion pass).
   *Follow-up (same day):* first open showed black for seconds while landmarks
   generated — fixed with a two-stage first build (stars-only scene publishes in
   milliseconds, nebulae follow when ready). Possible polish later: fade the
   landmarks in instead of popping.
3. **Surface unification** *(✅ done 2026-07-28, both apps build clean)* —
   CatalogView: spaceGradient + hidden scroll background + the shared luminous row
   treatment + `.tint(Theme.accent)`. Search unified on the **bottom capsule** (kept —
   it was a deliberate thumb-reach choice) extracted to
   `DesignSystem/LuminousSearchField`; ConstellationsView now uses it instead of
   `.searchable`. New `quietSurface()` (glass + hairline, no tint/glow) replaces all
   three flat `.black.opacity` plate variants (sky bottomPanel, StarColorLegend,
   HR/size plots). New `Theme.textSecondary` (0.65) / `Theme.textTertiary` (0.55)
   tokens swept through the chrome (ContentView, GalaxyMapView, MoreMenu,
   StarComparisonViews); DistanceReadout 0.38→0.55 and Galaxy hint 0.4→0.55 fix the
   worst contrast items; selection-card detail promoted caption2/0.5 → caption/
   secondary. Ad-hoc radii 22/24/26 collapsed onto `Theme.panelRadius`; plot radii
   12/14 onto `cardRadius` via quietSurface. One night: ContentView, MoreMenu, and
   GalaxyMapView backgrounds all use `Theme.spaceGradient` now. Shared
   `DesignSystem/DetailRow` replaces the three private copies (ConstellationsView's
   rows thereby gain the GlossaryButton affordance). SkyFilters' no-op Form-level
   `.listRowBackground` fixed (now per-Section, actually renders). Theme additions
   ported to Ecliptica. **Not done:** full 27-opacity sweep beyond the chrome
   (remaining ad-hoc values are mostly decorative strokes/washes, not text);
   TonightView/MoreMenu padding harmonization.
4. **Off-main sweep** *(✅ done 2026-07-28, builds clean, zero warnings)* —
   **F1:** Sun/Moon equatorial positions cached in `SolarEphemeris` on the 1.5 s
   refresh (Moon's is topocentric); per frame only the horizontal transform +
   projection run, so sidereal rotation stays smooth under the time scrubber but the
   Meeus/ELP series left the 120 Hz path. **F2:** `refreshSky` snapshots inputs and
   computes in `Task.detached` via `nonisolated static computeSky` (cancel-previous);
   assignments hop back. **F3:** `ARCameraController` caches the converted `CGImage`
   per ARFrame timestamp. **Catalog:** 109k sort/bucketing + per-star lowercase
   `StarFacts.searchKey` built off-actor once; `matchingStars` filters prebuilt keys
   (no per-keystroke allocation); `sortedDeepSky` static. **Constellations:**
   `rebuild()` deduped via `builtCatalogCount` guard (the `.onAppear` duplicate
   deleted) and built off-actor; `SkyFigureDetailView.stars`/`brightest` moved from
   computed properties (3 full scans per body eval) to one off-actor pass in `.task`.
   **Constellation3DView:** model build detached so the cover animation plays.
   **TonightView:** `.task(id:)` now keyed on the full coordinate (was latitude-only —
   longitude moves silently showed wrong rise/set), `computing` flag deleted in favor
   of task cancellation. Behavior note: Sun/Moon can lag ≤1° mid-scrub-drag for up
   to 1.5 s (equatorial cache cadence); corrected on release. Deferred to later: GM-2
   (galaxy camera through the render loop), MR-2 (drop CPU sprite copies), SV-1
   (SystemView per-frame Kepler), FilterSheet count(where:).
5. **Housekeeping sweep** *(✅ done 2026-07-28, builds clean, zero warnings)* —
   `MagnifyGesture` ×3 (ContentView, GalaxyMapView, Constellation3DView); MoreMenu on
   value-based navigation (`NavigationLink(value:)` + `navigationDestination(for:
   AppScreen.self)`); dead code deleted (`PlaceholderScreen`, `AppScreen.gradient`,
   `isPointingReady`, `projectToScreen`); GM-5 drag-snap fixed (track `dragPrevious`
   while throttling); GM-7 dive-epilogue task held + cancelled; `Task.sleep(for:)`
   in the debug harness; FilterSheet `count(where:)`; temperature bands unified in
   `TemperatureColor` (colour + adjective one table, `StarFacts.colourWord(forTemp:)`
   delegates); deprecated `overlay(_:)`/`background(_:)` → closure form at the
   flagged sites. **Deferred, deliberately:** `String(format:)` → FormatStyle sweep
   (dozens of sites; fold into the localization pass, which reworks all copy anyway);
   `ForEach(Array(x.enumerated()))` (the direct-enumerated conformance is a Swift
   6.2-runtime feature — risky against the iOS 18 deployment floor, and `Array()` is
   harmless); Constellation3DView's three 16 ms sleep loops → TimelineView (real
   refactor, goes with GM-2's camera-through-render-loop work); EX-1 `Task.detached`

6. **Destination dock** *(✅ done 2026-07-28, builds clean — added after the review;
   Elysia: the full-screen menu "makes it feel like a toy app")* — `MoreMenuView` /
   `DestinationCard` / `MenuBackground` deleted; the sky IS the app now. The Menu

   While covered: the sky `TimelineView` is `paused:`, the 1.5 s refresh skips, and
