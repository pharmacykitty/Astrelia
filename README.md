# Astrolabe

A point-at-the-sky planetarium for iOS with deep astrophysical data and a full
astrology layer — built to be genuinely beautiful.

Raise your phone toward the sky to see the real positions of stars, planets, and
other celestial bodies, accurately computed for your location and the current
instant. Tap anything for as much detail as exists — physical and astrological.

See [`CLAUDE.md`](CLAUDE.md) for the full vision, architecture, and roadmap.

## Layout

- `App/` — the SwiftUI iOS app (Swift 6, strict concurrency).
- `Packages/CelestialCore/` — platform-agnostic astronomy engine (no UI/sensor
  dependencies). The math/data spine: angles, time, coordinates, star catalog.
- `project.yml` — the Xcode project definition (the `.xcodeproj` is generated).

## The app (Xcode)

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen)
from `project.yml`, so it isn't committed. To open the app:

```sh
brew install xcodegen   # once
xcodegen generate       # writes Astrolabe.xcodeproj
open Astrolabe.xcodeproj
```

## The engine (CelestialCore)

```sh
cd Packages/CelestialCore
swift test
```

## Star catalog data

The full [HYG database](https://github.com/astronexus/HYG-Database) (~120k stars,
~34 MB) is **not** committed. Fetch it into `Data/` (git-ignored) when needed:

```sh
mkdir -p Data
curl -L -o Data/hygdata.csv \
  https://raw.githubusercontent.com/astronexus/HYG-Database/main/hyg/CURRENT/hygdata_v41.csv
```

Parse it with `StarCatalog.hyg(csv:)`.
